3. Machine Learning Algorithms
Q21. What is Linear Regression?

Linear Regression is an algorithm that predicts a continuous value by finding a linear relationship between input features and the target.

Q22. What is Random Forest Regression?

It is an algorithm that combines multiple decision trees and uses their average prediction for regression.

Q23. Difference between Linear Regression and Random Forest?
Linear Regression	Random Forest
Uses a linear relationship	Uses multiple decision trees
Simple model	Ensemble model
Easy to interpret	More complex
May miss complex patterns	Can learn complex patterns

Q24. What is a Decision Tree?

A Decision Tree makes predictions by splitting data based on conditions.

Q25. What is an ensemble learning method?

It combines multiple models to produce a better prediction.

Q26. What is n_estimators=100?

It means the Random Forest uses 100 decision trees.

R² measures how well the model explains the variation in the target values. Higher is generally better.

RMSE stands for Root Mean Squared Error. It measures the average size of prediction errors, with larger errors penalized more.
