3. K-Means Clustering
Q12. What is K-Means Clustering?

It is an unsupervised learning algorithm that groups data points into K clusters based on similarity.

Q13. What does K represent?

K represents the number of clusters.

Q14. What is a centroid?

A centroid is the center point of a cluster.

Q15. How does K-Means work?
1. Select K clusters.
2. Initialize cluster centroids.
3. Assign each data point to its nearest centroid.
4. Calculate new centroids.
5. Repeat until the clusters become stable.
Q16. What is the Elbow Method?

It is a method used to find the suitable number of clusters.

Q17. What is WCSS?

WCSS stands for Within-Cluster Sum of Squares. It measures the sum of squared distances between data points and their cluster centroids.

Q18. Why did you use the Elbow Method?

To identify the suitable number of clusters.

Q19. What is the optimal K in your assignment?

K = 3.

Q20. What does n_init=10 mean?

K-Means runs with 10 different centroid initializations and selects the best result.

Q21. What does random_state=42 do?

It helps produce reproducible results.
4. Hierarchical Clustering
Q22. What is Hierarchical Clustering?

It is an unsupervised learning algorithm that creates a hierarchy of clusters.

Q23. What are the types of Hierarchical Clustering?
- Agglomerative (bottom-up)
- Divisive (top-down)
Q24. Which type did you use?

Agglomerative Clustering.

Q25. What is Agglomerative Clustering?

It starts with each data point as a separate cluster and repeatedly merges the closest clusters.

Q26. What is linkage?

Linkage is a method used to calculate the distance between clusters.

Q27. Which linkage did you use?

Ward linkage.

Q28. What is Ward linkage?

It merges clusters in a way that minimizes the increase in within-cluster variance.

Q29. What is a dendrogram?

A dendrogram is a tree-like diagram that shows how clusters are merged.
5. PCA and Visualization
Q30. What is PCA?

PCA stands for Principal Component Analysis. It reduces the number of dimensions in data while preserving as much variation as possible.

Q31. Why did you use PCA?

To reduce the four selected features into two dimensions for visualization.

Q32. Does PCA perform clustering?

No. PCA only reduces dimensions. K-Means and Hierarchical Clustering perform the clustering.

Q33. What does n_components=2 mean?

It means we reduce the data to two principal components.

Q34. Why did you use a scatter plot?

To visualize the clusters in two dimensions.
