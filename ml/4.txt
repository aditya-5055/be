2. Gradient Descent Algorithm
Q8. What is the Gradient Descent formula?
\[
x_{\text{new}}=x_{\text{old}}-\alpha f'(x)
\]

Here, \(\alpha\) is the learning rate.

Q9. What is a learning rate?

Learning rate controls how big a step the algorithm takes during each update.

Q10. What happens if the learning rate is too high?

The algorithm may overshoot the minimum or fail to converge.

Q11. What happens if the learning rate is too low?

The algorithm takes very small steps and becomes slow.

Q12. What is convergence?

Convergence means the algorithm gets closer to a stable solution.

Q13. What is an iteration?

One complete update of the value of x is called an iteration.

Q14. What is a local minimum?

A local minimum is the lowest point in a nearby region of a function.

Q15. What is a global minimum?

A global minimum is the lowest value of the function over its entire domain.

5. Applications and Differences
Q31. Where is Gradient Descent used?
- Linear Regression
- Logistic Regression
- Artificial Neural Networks
- Deep Learning
Q32. What are the types of Gradient Descent?
1. Batch Gradient Descent
2. Stochastic Gradient Descent
3. Mini-batch Gradient Descent
Q33. Difference between Batch and Stochastic Gradient Descent?
- Batch Gradient Descent uses the complete training dataset for each update.
- Stochastic Gradient Descent uses one training example for each update.
Q34. What is the difference between Gradient Descent and Genetic Algorithm?

Gradient Descent uses gradients to find a minimum, while Genetic Algorithm uses ideas inspired by natural selection.

Q35. Does Gradient Descent always find the global minimum?

No. Depending on the function and starting point, it may converge to a local minimum or another stationary point.
